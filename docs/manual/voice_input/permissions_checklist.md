# Permissions Checklist — Mones

## Microphone Permission

Android:
- Pastikan AndroidManifest.xml memiliki permission RECORD_AUDIO.

iOS:
- Pastikan Info.plist memiliki NSMicrophoneUsageDescription.
- Teks permission harus Bahasa Indonesia atau jelas untuk user.

## Expected Copy

Aplikasi membutuhkan akses mikrofon untuk mencatat transaksi lewat suara.
